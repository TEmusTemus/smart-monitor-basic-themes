# Smart Monitor Basic Themes

Fallout/Pip-Boy landscape theme for a Turing 3.5-inch Smart Monitor Basic display.

## Fallout Landscape

The latest saved theme is in [`themes/Fallout_landscape`](themes/Fallout_landscape) and the installable archive is [`dist/Fallout_landscape-theme.zip`](dist/Fallout_landscape-theme.zip).

Features:

- 480x320 landscape Fallout-inspired artwork
- Native Smart Monitor Basic UI with the latest saved widget layout
- Live CPU/GPU/RAM/HDD/network values through native widgets
- Matching Fallout startup frames `X0.jpg` through `X4.jpg` to prevent default-art rotation

Copy the theme files into a dedicated theme folder, set Smart Monitor Basic's target UI to `Fallout_landscape.ui`, and keep a backup of the original theme first.
